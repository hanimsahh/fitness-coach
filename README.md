# FitCoach AI 🧠💪

An AI-powered fitness coaching web application that provides personalised workout plans, nutrition tracking, progress analytics, hydration tracking, and motivational insights.

## Features

* 🤖 AI Fitness Coach Chat
* 🍽️ Smart Nutrition Logging
* 📊 Progress & Weight Tracking
* 🏋️ Personalised Workout Plans
* 💧 Water Intake Tracker
* 📈 Weekly Insights & Analytics
* 📚 Exercise Library
* 🔐 User Authentication System

## Technologies Used

* Python
* Flask
* HTML / CSS / JavaScript
* Google Cloud Platform
* GitHub
* USDA FoodData Central API

## AI Functionality

The application uses AI-driven agents to:

* Analyse meals and estimate calories/macros
* Generate personalised fitness recommendations
* Create adaptive workout plans
* Provide motivational health insights

## Deployment

Deployed using Google Cloud Platform (GCP).
